# SelfHub — فهرست کامل قابلیت‌ها (نسخهٔ ۲)

ربات روی **Bot API رسمی تلگرام** + پنل وب. هیچ ربات هلپری، هیچ API Hash، هیچ سرور دائمی لازم نیست.

## ۱) مدیریت و نظارت گروه

| قابلیت | جزئیات |
|---|---|
| 🌊 ضدفلود | پنجرهٔ لغوانی (ثانیه/تعداد) + اقدام قابل‌انتخاب (حذف، اخطار، سکوت، اخراج، بن) |
| 🔁 ضدتکرار | شمارش پیام‌های یکسانِ نرمال‌شده در پنجرهٔ زمانی |
| 🚫 کلمات ممنوعه | تطبیق فارسی‌آگاه (ی/ك عربی، ارقام فارسی، اعراب، ZWJ، تتویه) + `*` به‌عنوان wildcard + پیشوند `regex:` |
| ✍️ تلورانس تایپو | `fuzzyWordHit` برای دورزدن‌های ساده (فاصله، کاراکتر اضافه) |
| 🔗 فیلتر لینک | لینک معمولی، لینک کوتاه (`t.me/…`)، و تشخیص **لینک دعوت** (`t.me/+…`, `joinchat`) با شدت بیشتر؛ دامنهٔ خودِ کانال/گروه قابل استثنا |
| 🔠 بزرگ‌نویسی افراطی | نسبت حروف بزرگ‌بالای آگاه به یونیکد |
| 📏 طول پیام | سقف نویسه |
| 🖼 رسانه | مسدودکردن نوع رسانه (استیکر، گیف، ویس، نظرسنجی، مخاطب، موقعیت و…) |
| 👤 عضو مشکوک | بن خودکار بر اساس الگوی نام/یوزرنیم هنگام جوین |
| 🤖 کپچای انسانی | پیام خصوصی + دکمهٔ تأیید؛ عدم‌تأیید تا مهلت → اخراج خودکار توسط کران |
| ⚠️ سیستم اخطار | شمارش اخطار هر کاربر در هر چت، نردبان: اخطار → (سقف) → سکوت/اخراج/بن |
| ✏️ بازرسی ویرایش | پیام ویرایش‌شده دوباره فیلتر می‌شود (دورزدن فیلتر با ادیت ممکن نیست) |
| 🧾 لاگ مدیریتی | هر اقدام در دیتابیس + ارجاع به «چت لاگ» اختیاری + `/log` |

**معافیت‌ها:** ادمین‌های چت، خودِ ربات، و ادمین‌های سراسری پنل از فیلترهای محتوایی معاف‌اند. کاربرِ غیرادمین در کانال (پست رسمی کانال) بررسی نمی‌شود چون قابل تنبیه نیست.

## ۲) تعامل با اعضا

- 👋 خوش‌آمدگویی با قالب و متغیرها: `{name} {first} {username} {id} {group} {count} {time} {date}`
- 👋 پیام خروج عضو (اختیاری)
- 📖 قاعده‌ها با `/rules` (متن از پنل)
- 💬 پاسخ خودکار کلیدواژه‌ای: چهار حالت `contains` / `exact` / `starts` / `regex`، سقف دو پاسخ به هر پیام، شمارش برخورد هر قاعده
- 📝 نوت‌ها: `/save نام متن` و فراخوانی با `#نام` + شمارش بازدید + `/notes` و `/clear`

## ۳) زمان‌بند و یادآور

- `+20m` ، `+2h` ، `۴۵ ثانیه` ، `30 دقیقه دیگه`
- `14:30` (اگر گذشته باشد فردا) ، `امروز ۸:۰۰` ، `فردا ۸:۰۰`
- `2026-10-09 08:00`
- `every 30m` / `هر ۳۰ دقیقه` برای پست تکراری (حداقل ۳۰ ثانیه)
- منطقهٔ زمانی قابل‌تنظیم (`tzOffsetMin`، پیش‌فرض تهران ۲۱۰)
- اجرا توسط **Cron Trigger** Cloudflare؛ اگر ارسال موقتاً ناموفق باشد در صف می‌ماند و دقیقهٔ بعد دوباره تلاش می‌کند؛ اگر چت حذف/اخراج باشد کار حذف می‌شود تا صف گیر نکند
- `/remind` `/schedule` `/reminders` `/rm` و مدیریت کامل از پنل (اجرای دستی، توقف، حذف)

## ۴) ابزارهای مدیریتی از تلگرام

`/warn` `/warns` `/unwarn` `/mute` `/unmute` `/kick` `/ban` `/unban` `/del` `/purge` `/pin` `/unpin` `/poll` `/setlog` `/setname` `/id` `/status` `/stats` `/log` `/ping` `/help <دستور>`

دستورات ادمین با بررسی **ادمینِ همان چت** از طریق `getChatMember` (با کش ۱۰ دقیقه‌ای) محافظت می‌شوند؛ `adminOnlyCommands` قابل خاموش‌کردن است.

## ۵) اطلاعیه (فقط برای چت‌های opt-in)

- هر چت با `/sub` خودش را اضافه و با `/unsub` حذف می‌کند؛ خروج ربات از چت، عضویت را خودکار باطل می‌کند
- `/broadcast متن` فقط توسط ادمین پنل، با سقف تعداد در هر اجرا و فاصلهٔ زمانی بین ارسال‌ها
- باقی‌مانده در صف می‌ماند و در دقیقهٔ بعد ادامه پیدا می‌کند (به‌جای یک حلقهٔ طولانی که سقف CPU Worker را می‌شکند)

> این قابلیت **فقط** برای چت‌هایی است که خودشان عضو شده‌اند. هیچ ابزاری برای پیام انبوه به کاربران ناشناس، اسکرپ اعضا یا عضویت خودکار در لینک‌ها وجود ندارد و اضافه نخواهد شد.

## ۶) آمار و پنل

- شمارش روزانهٔ هر چت: پیام، عضو تازه، حذف‌شده، اخطار، سکوت، بن، پاسخ، دستور + سری ساعتی (۷ روز نگه‌داشته می‌شود)
- داشبورد: روند پیام‌ها، نمودار ۲۴ ساعت، پرتراکم‌ترین چت‌ها، رشد ۷ روزه، رویدادهای زنده
- `/stats [روز]` داخل تلگرام با نمودار میله‌ای متنی
- خروجی **CSV** آمار و **JSON** تنظیمات از پنل
- مدیریت از راه دور چت‌ها، قاعده‌ها، کلمات، کپچا، نوت‌ها، کلیدواژه‌ها و زمان‌بند
- **آزمون فیلتر**: متن نمونه را با تنظیمات همان چت می‌سنجد و می‌گوید چه اتفاقی می‌افتد — قبل از اعمال روی گروه واقعی

## ۷) امنیت پنل

- رمز عبور با **PBKDF2-SHA256 (۲۱۰ هزار تکرار)** + salt تصادفی، حداقل ۱۰ نویسه و ردِ الگوهای رایج
- کوکی نشست ۱۲ ساعته، `HttpOnly` + `SameSite=Lax` + امضای HMAC؛ بررسی امضا با `crypto.subtle.verify` (زمان‌ثابت)
- قفل ورود پس از ۵ تلاش ناموفق به‌مدت ۱۵ دقیقه — **روی دیسک (SQLite)** ذخیره می‌شود، برخلاف نسخهٔ ۱ که در حافظه بود و با هر تخلیهٔ Durable Object ریست می‌شد
- محافظت CSRF با هدر `x-selfhub: 1` روی همهٔ درخواست‌های تغییردهنده
- توکن ربات با **AES-GCM** رمزنگاری و ذخیره می‌شود؛ بذر کلید از Secret محیط یا یک مقدار تصادفی ذخیره‌شده
- وب‌هوک با `secret_token` تلگرام و بررسی همان رمز در ورودی؛ حذف خودکار updateهای تکراری با `update_id`

## ۸) چیزهایی که عمداً وجود ندارد

اسکرپ اعضا، پیام انبوه به لیست کاربر، عضویت خودکار در گروه‌ها، ویو خودکار استوری، تگ‌آل انبوه، «پاک‌کردن همهٔ پیام‌های دیگران»، حالت شبح، خودخوان‌کردن، چرخش خودکار بیو/پروفایل، مدیریت نشست‌ها، ورود با اکانت کاربری، ساخت خودکار API در `my.telegram.org`، و هر نوع اتوماسیان بازی/ایردراپ.

دلیل: یا اسپم و آزار است، یا دورزدن محدودیت تلگرام، یا تقلب عليه یک سرویس. فهرست کامل و گفت‌وگوی پشت آن در [`REMOVED.md`](./REMOVED.md).
