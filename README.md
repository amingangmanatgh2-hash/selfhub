# 🤖 SelfHub — سلف‌بات تلگرام بدون ربات هلپر

**SelfHub** یک پلتفرم کامل سلف‌بات تلگرام است که **کاملاً از پنل وب** و با **رمز عبور ادمین** کنترل می‌شود — **هیچ ربات هلپری لازم نیست** (این دقیقاً همان مشکل اصلی سلف‌بات‌های موجود بود که اینجا حل شده).

این پروژه حاصل ترکیب و بازنویسی **۳ سورس اصلی** + مطالعه‌ی **بیش از ۵۰ سورس و ریپازیتوری دیگر** است (شرح کامل در [`RESEARCH.md`](./RESEARCH.md)) و روی **Cloudflare Workers** اجرا می‌شود — بدون نیاز به سرور، بدون VPS.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/amingangmanatgh2-hash/Gaming-hub-)

> راهنمای گام‌به‌گام دپلوی: [`DEPLOY.md`](./DEPLOY.md)

---

## ⚠️ هشدار مهم

استفاده از سلف‌بات (اتوماسیون اکانت کاربری) **خلاف شرایط استفاده تلگرام** است و ممکن است منجر به محدودیت (اسپم‌بن) یا بن شدن اکانت شود. تمام ابزارهای ارسال انبوه این پروژه به‌صورت پیش‌فرض با **مکث تصادفی و سقف روزانه** کار می‌کنند تا ریسک کمینه شود، اما مسئولیت نهایی با شماست. از اکانت اصلی‌تان استفاده نکنید و عاقلانه رفتار کنید.

## 🎯 چرا SelfHub؟ (فرقش با بقیه)

| مشکل سلف‌بات‌های قدیمی | راه‌حل SelfHub |
|---|---|
| برای کنترل پنل باید **ربات هلپر** می‌ساختی | ❌ هیچ رباتی لازم نیست — همه‌چیز از پنل وب |
| ستاپ سخت: ویرایش فایل Information.py و… | ✅ ویزارد نصب تحت وب در ۳۰ ثانیه |
| هر بار ری‌استارت سرور، سلف خاموش | ✅ اجرای دائمی روی Cloudflare + بازیابی خودکار اتصال |
| فقط یک اکانت | ✅ مدیریت **چند سلف** همزمان + اکانت رباتی (اختیاری) |
| کنترل فقط داخل تلگرام | ✅ پنل وب فارسی + لاگ زنده + اعلان‌ها + دستورات چتی هم دارد |

## ✨ ۲۰ قابلیت اصلی (و چند بونوس)

| # | قابلیت | توضیح |
|---|---|---|
| ۱ | 💬 **منشی هوشمند** | پاسخ خودکار با ۴ حالت: همیشه / فقط پیام اول هر نفر / هنگام آفلاین بودن / فقط با کلیدواژه + لیست پاسخ‌های کلیدواژه‌ای |
| ۲ | 💤 **حالت غیبت (AFK)** | پاسخ خودکار در غیاب با متن دلخواه + اطلاع منشن‌ها در پنل |
| ۳ | 🔁 **فوروارد هوشمند** | قوانین «از → به» با فیلتر کلیدواژه/ریجکس و حالت فوروارد یا کپی (ایده از tgcf) |
| ۴ | ⏰ **زمان‌بند ارسال** | ارسال پیام در زمان مشخص یا تکرارشونده (هر X دقیقه) |
| ۵ | 📨 **پیام انبوه انسانی‌گونه** | ارسال به لیست اهداف با تاخیر تصادفی، سقف روزانه و مدیریت خودکار FloodWait |
| ۶ | ⛏ **اسکرپر اعضا** | دریافت اعضای گروه + خروجی CSV + ارسال مستقیم لیست به پیام انبوه |
| ۷ | ➕ **جوینر خودکار** | عضویت در لیست لینک‌ها با فاصله امن |
| ۸ | 👁 **ویو خودکار استوری** | دیدن خودکار استوری‌های مخاطبین انتخابی |
| ۹ | ❤️ **ری‌اکشن خودکار** | واکنش تصادفی با احتمال دلخواه در چت‌های مشخص |
| ۱۰ | 👻 **حالت شبح** | آفلاین دیده شدن + بدون تیک خوانده‌شدن + بدون نشانگر تایپ |
| ۱۱ | 📖 **خودخوان پیام‌ها** | علامت خوانده‌شدن خودکار پی‌وی/گروه/کانال/منشن‌ها (به‌تفکیک) |
| ۱۲ | 🛡 **ضداسپم گروه** | حذف خودکار پیام حاوی کلمات ممنوع + اختیار اخراج یا بن |
| ۱۳ | 👋 **خوش‌آمدگویی گروه** | پیام خوش‌آمد اعضای جدید با قالب `{name}` |
| ۱۴ | 🔎 **ردیاب کلیدواژه** | اعلان فوری در پنل (و اختیاراً در یک چت) وقتی کلیدواژه‌ای دیدم شود |
| ۱۵ | 💾 **ذخیره‌خودکار رسانه** | فوروارد خودکار عکس/ویدیو/ویس چت‌های خاص به Saved Messages یا چت دلخواه |
| ۱۶ | 🧹 **پاک‌سازی انبوه** | حذف پیام‌های خودتان یا همه (با فیلتر نوع رسانه) |
| ۱۷ | 📣 **تگ‌آل** | منشن همه اعضای گروه (از پنل یا با دستور چتی) |
| ۱۸ | ⌨️ **دستورات چتی** | `.ping` `.stats` `.id` `.info` `.afk` `.purge` `.tagall` `.join` `.ghost` — بدون هیچ رباتی |
| ۱۹ | 🎭 **اتوماسیون پروفایل** | نام و بیوی زمان‌دار `{time}` + چرخش خودکار بیو (برداشت از سورس پایه) |
| ۲۰ | 🔐 **مدیریت نشست‌ها** | دیدن همه دستگاه‌های متصل + خاتمه نشست‌ها + **هشدار ورود جدید** |

**بونوس‌ها:** چند-اکانتی + مدیریت از یک پنل ۲۱، آمار و سلامت هر اکانت (FloodWait، تعداد ارسال و…) ۲۲، بکاپ رمزنگاری‌شده AES-GCM و بازیابی ۲۳، حالت ربات اختیاری با Bot Token (بدون نیاز به هلپر) ۲۴، لاگ زنده SSE در پنل ۲۵، حالت نمایشی (دمو) بدون نیاز به اکانت واقعی ۲۶.

## 🚀 راه‌اندازی

### ۱) دپلوی روی Cloudflare (پیشنهادی)

ساده‌ترین راه، دکمه‌ی **Deploy to Cloudflare** بالای همین فایل است. راهنمای کامل در [`DEPLOY.md`](./DEPLOY.md).

خلاصه:

```bash
git clone https://github.com/amingangmanatgh2-hash/Gaming-hub-.git
cd Gaming-hub-
npm install
npx wrangler login
npx wrangler deploy
```

### ۲) ویزارد نصب (منوی ستاپ)

بعد از باز کردن سایت، در اولین بازدید فرم نصب نمایش داده می‌شود و این موارد را می‌گیرد:

- **API ID** و **API Hash** — از [my.telegram.org](https://my.telegram.org) (بخش API development tools)
- **Bot Token** — *اختیاری*؛ فقط اگر بخواهید یک اکانت رباتی هم به پنل اضافه کنید. **برای سلف‌ها هیچ رباتی لازم نیست.**
- **رمز عبور ادمین** — حداقل ۸ نویسه، با نمایش قدرت رمز

از این به بعد، **هر بار که به سایت بیایید** باید همین رمز را وارد کنید (کوکی نشست ۲ ساعته و مرورگر-بستنی است؛ ۵ تلاش ناموفق = قفل ۵ دقیقه‌ای).

### ۳) افزودن سلف

بخش **اکانت‌ها ← افزودن اکانت**: شماره را وارد کنید → کد تأیید تلگرام → (در صورت داشتن) رمز دو مرحله‌ای. تمام. نشست به‌صورت رمزنگاری‌شده ذخیره می‌شود و اتصال دائمی می‌ماند.

> 💡 مطمئن نیستید؟ در همان صفحه دکمه **«اکانت نمایشی»** را بزنید تا کل پنل را بدون اکانت واقعی بگردید.

## ⌨️ دستورات چتی (اختیاری، قابل تغییر پیشوند)

دستورات را خودتان در هر چتی که عضوید می‌نویسید و سلف همان لحظه اجرا می‌کند:

```
.ping                → تست سرعت
.stats               → آمار کامل اکانت
.id                  → شناسه چت
.info                → اطلاعات کاربر (با ریپلای)
.afk [متن] / .afk off → حالت غیبت
.read                → خواندن چت
.purge [تعداد]       → حذف پیام‌های خودتان
.tagall [متن]        → منشن همه اعضا
.join <لینک>         → عضویت
.ghost on|off        → حالت شبح
```

## 🏗 معماری

```
┌────────────────────────────────────────────────┐
│                 Cloudflare Worker               │
│  پنل (Static Assets) + API + احراز هویت (HMAC)  │
└───────────────┬───────────────────┬────────────┘
                │                   │
      ┌─────────▼────────┐ ┌────────▼─────────┐
      │  HubDO (مرکزی)   │ │  SelfDO × N      │
      │  تنظیمات، لاگ‌ها، │ │  هر اکانت:       │
      │  اکانت‌ها، SSE    │ │  کلاینت mtcute   │
      └──────────────────┘ │  + موتور امکانات │
                           │  + زمان‌بند alarm │
                           └──────────────────┘
                                     │ WebSocket (wss://…web.telegram.org/apiws)
                              📡 سرورهای تلگرام
```

- **موتور MTProto:** [mtcute](https://github.com/mtcute/mtcute) — پیاده‌سازی رسمیِ سازگار با Cloudflare Workers
- **ترنسپورت:** WebSocket به اندپوینت‌های رسمی تلگرام (همان که کلاینت وب تلگرام استفاده می‌کند)
- **کریپتو:** WebCrypto + WASM باندل‌شده (AES-IGE و…)
- **ذخیره‌سازی:** نشست‌ها AES-GCM رمزنگاری و در Durable Object ذخیره می‌شوند
- **رمز ادمین:** PBKDF2-SHA256 با ۱۰۰,۰۰۰ تکرار
- **بدون وابستگی خارجی:** همه‌چیز روی زیرساخت خودتان

## ⚙️ نکته‌های اجرا و هزینه

- اتصال دائمی سلف = یک Durable Object همیشه فعال. برای استفاده ۲۴/۷ **پلن Workers Paid (۵ دلار در ماه)** لازم است؛ مصرف معمول یک سلف در محدوده‌ی اعتبار ماهانه‌ی همین پلن جا می‌شود.
- **`wrangler dev` لوکال خروجی WebSocket ندارد** (محدودیت شناخته‌شده‌ی dev لوکال) — پنل و حالت نمایشی کامل کار می‌کنند اما برای اتصال واقعی به تلگرام دپلوی کنید یا از `npx wrangler dev --remote` استفاده کنید.
- برای تست سلامت اتصال خروجی بعد از دپلوی: `GET /api/wstest`
